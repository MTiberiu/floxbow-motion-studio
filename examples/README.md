# Technical examples

This directory contains short API demonstrations, not videos and not project templates. The desktop project browser only discovers manifests in `projects/<id>/project.json`, so these examples never appear as user projects at startup.

The Capabilities Explorer registry points to each example and uses the Remotion examples in `capabilities/visual.tsx` and `capabilities/subtitle.tsx` as real component previews. API-only examples show the source directly. Keep examples neutral, small, self-contained, and typechecked. Add a user video only under `projects/` after the user asks to create one.
