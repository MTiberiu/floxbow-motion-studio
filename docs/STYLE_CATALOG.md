# Capability catalog

Machine-readable discovery lives at `packages/animation-library/registry.json` and is shown in the Capabilities tab.

- **Style**: editorial-dark defines ink backgrounds, lime highlights, spacious layout and bold system typography. It is a visual convention, not executable animation.
- **Component**: KineticText, ChatBubble, ComicPop, Counter, KaraokeWords and Fade have reusable props and deterministic frame behavior.
- **Scene template**: title-scene combines layout and components; copy `projects/first-tutorial/scenes/TitleScene.tsx` into a project and adapt.
- **Composition**: first-tutorial is a complete timed video; copy a project when a whole storyboard is appropriate.

See CREATE_ANIMATION for every component's parameters and runnable usages. All examples are local and have no external paid media dependency. Add a catalog entry only after its implementation and working example exist.
