# Module discovery

Use this index to choose one guide for the current task. It describes current source boundaries, not a plugin system. Status reflects code and documentation at the index's reviewed commit; follow the linked guide for limits and verify exports in source when changing a public contract.

`Partial` means an integration is intentionally limited, not that its supported connections are absent. In the live development editor, a registered Media Registry soundtrack can become a visible Audio-track clip, play through the shared Remotion transport, appear in preview, and render into MP4. MP4 audio can be separated into its own Timeline clip while keeping the video clip muted; both clips use the same registered source and Remotion transport. The local Whisper worker can create unverified editable subtitle clips from the soundtrack or embedded audio of a selected Timeline video clip. Video cue timing starts at the clip's Timeline position. Registry editing and local transcription are not exposed in the built snapshot; media collection, audio automation and waveform editing are also not implemented. `Narration` is a separate composition-owned audio component. Read the linked guides before choosing an implementation.

Capability-registry parameters describe component APIs, not necessarily Timeline or Inspector controls. Check each capability's timeline integration and limits, then inspect its actual `EditableComponent.fields` and exports before promising that a value is editable. Composition-level or render-only components and imported images do not become editable clips by being used in a project.

Core **Text**, **Image**, and **Video** are implemented editor elements available in every editable project without activating a specialized module. Media source registration and Timeline placement are separate operations; see [Project Media](PROJECT_MEDIA.md), [the Image clip contract](STANDALONE_IMAGE.md), and [the Video clip contract](STANDALONE_VIDEO.md). Core Canvas provides the shared selection and transform layer for opted-in visual elements; see [its contract](CANVAS_CORE.md). Current opted-in application elements are Text, Image, Video, and subtitles. Other visuals need the same validated contract before spatial editing is available.

## Examples and proposals

Technical demonstrations live under [`examples/capabilities/`](../examples/README.md); they are not user projects. Existing project examples, if any, are separate from reusable capabilities.

Proposals and experiments are not available features. [Review & Annotations](../improvements/proposals/ai-documentation-architecture.md) is proposed only: there is no implemented review-annotation module or project-data contract. Cross-module product ideas live in [`management/BACKLOG.md`](../management/BACKLOG.md); engineering designs and investigations live under [`improvements/`](../improvements/experiments/README.md). Do not infer implementation status from a proposal or backlog entry.
